We use [Ruff](https://docs.astral.sh/ruff/) to ensure our Python code is clean, consistent, and follows best practices. Ruff replaces multiple tools like Flake8, Black, and isort with a single, extremely fast executable.

### Installation

Ruff is included in the project's development dependencies. You can ensure it is installed by running:

```bash
pip install ruff
```

### Usage

#### Linting (Checking for errors)
To check the entire project for linting errors and logical issues, run:

```bash
ruff check .
```

If you want Ruff to automatically fix safe violations (like unused imports), use:

```bash
ruff check --fix .
```

#### Formatting (Code style)
We follow a strict formatting standard. To automatically format your code to match the project style:

```bash
ruff format .
```

<Tip>
  Running `ruff format .` before submitting a Pull Request is highly recommended to avoid CI failures related to code style.
</Tip>

### Configuration

Our linting and formatting rules are defined in `pyproject.toml`. We follow PEP 8 standards with a target version of Python 3.12 and a line-length limit of 88 characters.

Key configuration details:

*   **Target Version**: `py312` (Python 3.12).
*   **Line Length**: 88 characters (matching the Black code style).
*   **Selected Rules**: 
    *   `E`/`W`: Pycodestyle errors and warnings.
    *   `F`: Pyflakes checks.
    *   `I`: Isort for automated import sorting.
*   **Import Sorting**: `combine-as-imports` is enabled to keep imports concise.

```toml
[tool.ruff]
target-version = "py312"
line-length = 88
lint.select = ["E", "F", "W", "I"]
lint.ignore = []

[tool.ruff.lint.isort]
combine-as-imports = true
```
