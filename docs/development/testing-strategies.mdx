You can validate the modular codebase with the existing pytest suite under `tests/`. The tests cover the playback commands, queue behavior, event handlers, permissions checks, and the connection bootstrap that the modular architecture depends on.

## Run the full suite

```bash
pytest tests -v
```

## Run focused modules

```bash
pytest tests/test_playback.py -v
pytest tests/test_queue.py -v
pytest tests/test_events.py -v
pytest tests/test_permissions.py -v
pytest tests/test_connection.py -v
```

## Run one specific test

```bash
pytest tests/test_playback.py::test_previous_command_navigates_unified_history -v
```

## Watch for changes during development

```bash
ptw
```

This command watches the Python files and re-runs the suite whenever you save a change, which makes it easier to catch regressions while you work on the modular cog layout.
