# Command overview

You can use 18 slash commands in this bot. The command set is split between the main music cog, the DJ controls, and the utility helpers. The `/help` command is dynamic: it shows the full command index by default and can also display usage details for a specific command when you provide the optional `command` argument.

## Command groups

| Group | Commands |
| --- | --- |
| Music | `/play`, `/queue`, `/nowplaying`, `/join`, `/voteskip` |
| Queue and playback | `/shuffle`, `/clearqueue`, `/previous`, `/remove` |
| DJ controls | `/skip`, `/pause`, `/resume`, `/stop`, `/volume`, `/loop`, `/autoplay` |
| Utility | `/ping`, `/help` |

This set currently contains 18 slash commands in total: 5 general music controls, 4 queue-management helpers, 7 DJ-only controls, and 2 utility commands.

## What to read next

- Use [Playback](/commands/playback) for the detailed command walkthrough.
- Use [Queue](/commands/queue) for pagination, shuffle, and clear-queue behavior.
- Use [Utility](/commands/utility) for the help and diagnostics commands.

<Note>
  DJ-only commands require the DJ role or Administrator permission. The shared permission decorator in `core/decorators.py` enforces this check.
</Note>
