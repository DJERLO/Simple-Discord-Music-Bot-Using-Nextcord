Following a **docs-as-code** workflow allows us to treat documentation with the same rigor as our bot logic. We use the Mintlify CLI to ensure all content is validated before reaching production.

## Install the CLI

### Prerequisites

* [Node.js](https://nodejs.org/en) v20.17.0+ (LTS versions recommended)

### Installation

<CodeGroup>
  ```bash npm
  npm i -g mint
  ```

  ```bash pnpm
  pnpm add -g mint
  ```
</CodeGroup>

---

## Contributor commands

If you are contributing content, use these commands (via npm wrappers) to verify your work.

### Local preview
Run this to start a live-reloading server at `localhost:3000`.
```bash
npm run docs:dev
```

### Validation
Run this to catch structural errors or configuration issues in `docs.json`.
```bash
npm run docs:validate
```

### Link checking
Run this when you add or rename pages to confirm all internal paths still resolve.
```bash
npm run docs:links
```

---

## Maintainer commands

These commands are typically reserved for the **Owner** or **Team** to manage the documentation infrastructure.

### Update CLI
If the local preview differs from production, sync your CLI version:
```bash
mint update
```

### Create or scrape content
For initializing new sections or migrating documentation from external sources:
```bash
mint new [directory]
mint scrape <url>
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Error: Could not load the 'sharp' module">
    This usually happens due to an outdated Node.js version.
    1. Uninstall: `npm uninstall -g mint`
    2. Upgrade to Node.js v20.17.0+.
    3. Reinstall: `npm install -g mint`
  </Accordion>

  <Accordion title="Issue: Encountering an unknown error">
    **Solution**: Delete the `~/.mintlify` folder in your user home directory and run `npm run docs:dev` again.
  </Accordion>

  <Accordion title="Error: permission denied">
    This occurs if you lack global install permissions.
    **Solution**: Use `sudo npm i -g mint` on macOS/Linux, or run your terminal as Administrator on Windows.
  </Accordion>

  <Accordion title="mintlify vs mint package">
    If you have both `mint` and `mintlify` packages installed, they will conflict.
    **Solution**:
    ```bash
    npm uninstall -g mintlify
    npm cache clean --force
    npm i -g mint
    ```
  </Accordion>

  <Accordion title="Client version shows 'none'">
    This happens when a corporate firewall or VPN blocks the CLI from downloading the client app.
    **Solution**: Add `releases.mintlify.com` to your network allowlist.
  </Accordion>
</AccordionGroup>
