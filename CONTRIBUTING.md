# Contributing

Thank you for helping improve this project.

For the full contributor guide, see the live documentation:
https://mintlify.wiki/DJERLO/Simple-Discord-Music-Bot-Using-Nextcord

When you make code changes, keep the modular structure introduced in v1.10 in mind. Place new behavior in the existing `cogs/`, `core/`, and `ui/` layout rather than adding unrelated logic to one file.
